# image-prompt-hub · 图片提示词库管理员（开源版）

> 隆森AI 开源技能包 · MIT 许可
> 完整版（21,719 条数据底座 / 6+1 精选包 / 工作台模块）见 README 入口

---

## 1. 是什么

图片提示词模板库管理：**输入一句话需求 → 匹配最佳提示词模板 → 复制去出图**（GPT-Image 2/即梦/Midjourney/Flux/SD 等）。

## 2. 分类体系（8 场景 × 风格 × 模型）

| 场景 | 覆盖 |
|:--|:--|
| 电商/带货 | 商品图/淘宝主图/详情页/促销海报 |
| 社媒/种草 | 小红书封面/抖音封面/朋友圈/头像 |
| 品牌/营销 | 品牌海报/广告/banner/Logo/VI |
| 人像/写真 | 证件照/写真/时尚穿搭/美妆 |
| 艺术/插画 | 插画/漫画/动漫/3D艺术/数字艺术 |
| 产品/设计 | UI界面/App/网页/包装/工业设计 |
| 内容/知识 | 信息图/知识卡片/PPT/教育课件 |
| 生活/场景 | 风景/旅行/美食/家居/宠物/建筑 |

## 3. 快速开始（检索示例数据）

```bash
# 开源版带 20 条示例数据（examples/），跑检索：
python3 scripts/search_demo.py "小红书 护肤 极简"
# 输出匹配的模板标题 + 完整提示词 + 场景
```

完整数据底座（21,719 条）检索见 README 引流入口（工作台模块 / 精选包）。
