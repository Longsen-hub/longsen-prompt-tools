# AI生成向分镜表模板（12字段）

> 输出规范：本表是 video-prompt-reverse 子skill 交付物3 的标准格式。
> 借鉴：video-spec-builder 分镜规格化 + Seedance2-Storyboard-Generator 时间轴 + 26号分镜表 12 字段（AI生成向变体）。

## 整片头部信息

```markdown
# 视频提示词逆向 · 分镜表

- 原片标题：（用户提供或转写识别）
- 原片时长：（秒）
- 行业基准：（原视频所属行业——复刻禁止跨行业）
- 引擎适配：（即梦 / 可灵 / Seedance / 海螺 / 通义万相，多选）
- 整片风格锁：（一句话，如"真实手机拍摄感 + 冷色调 + 无音乐"）
- 一致性锚点清单：（角色属性/产品属性/场景属性，逐项锁定）
```

## 字段填写规则

**镜号**：01 起连续编号，与 Step1 镜头切分结果一一对应。

**时间轴**：格式 `0:00-0:03 (3s)`，精确到秒（video-spec-builder 纪律：镜头时长≥4秒必须解释表达什么，≤1秒必须有强视觉刺激）。

**景别**（8 种，ECU-EWS 扩展）：
- ECU 大特写（瞳孔/面料纹路）
- CU 特写（脸/手/产品）
- MCU 中近景（胸部以上）
- MS 中景（腰部以上）
- MLS 中全景（膝部以上）
- WS 全景（全身+环境）
- VWS 远景（环境建立）
- EWS 大远景（极远环境）

**运镜**：固定/手持（呼吸感）/推/拉/摇/移/升降/环绕/跟随/主观POV。

**画面描述**：主体 + 构图 + 背景三要素；不允许"空帧"——每个镜头必须有明确信息载荷。

**Prompt片段**：单镜头可执行提示词，结构 = 景别+主体+动作+环境+光线+运镜+时长+排除项（英文可执行版+中文对照）。

**参考图**：对应原片抽帧图（`@frame_XX` 引用，图生视频时用）。

**转场**：硬切/叠化/滑入/匹配剪辑/遮罩转场/无（首镜）。

**台词/情绪**：该镜头口播/旁白逐字 + 说话人情绪状态（愤怒/平静/兴奋…）。

**物理细节**：真实性来源——衣物随动作滑落、头发滞后一帧、床单褶皱、产品反光、阴影方向。

**排除项**：该镜头 STRICTLY AVOID——No warped hands / No duplicated limbs / No morphing / No flicker / No identity drift / No text drift（按需选）。

**一致性锚点**：跨镜头锁定——人物属性（发型/脸/服装/配饰）、产品属性（框型/材质/比例）、场景属性（房间/道具摆放），换场景只换环境不换人。

## 自检清单（生成后强制）

- [ ] 每镜头都有信息载荷（无空帧）
- [ ] 时间轴连续无断档、总时长=原片时长
- [ ] 景别/运镜/转场覆盖原片实际呈现
- [ ] 台词逐字对齐转写稿
- [ ] 一致性锚点覆盖全部镜头（跨镜头角色/产品不崩）
- [ ] 每镜头有排除项（负面清单）
- [ ] 行业一致性：未跨越原视频行业
- [ ] 零 em-dash（GB/T 15834）
